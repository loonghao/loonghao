## What I Do

I design and build AI-native creative pipelines: tools that connect DCC software, game production, asset workflows, production databases, messaging systems and intelligent agents.

My work sits at the intersection of creative production and serious engineering. I care about tools that artists actually want to use, systems that technical directors can maintain, and AI workflows that survive contact with real projects.

```yaml
identity:
  role: Senior Pipeline TD / AI Engineer
  focus: AI-native creative production systems
  primary_languages: Rust + Python
  experience: 12+ years across games, VFX, tools and automation
  mission: turn complex production workflows into reliable creative tools

signature_work:
  - MCP servers for creative tools and production platforms
  - DCC automation for Maya, Photoshop, ShotGrid and pipeline systems
  - Rust and Python tools for reliable automation, services and agent workflows
  - production workflows for artists, TDs, engineers and supervisors
```

## Why AI-Native

AI-native does not mean sprinkling a chatbot on top of an old workflow.

For me, it means designing software so an AI system can understand context, call the right tools, respect production rules, and help people move faster without breaking the creative process.

| Strength | What It Means |
| --- | --- |
| **AI-native engineering** | I design AI into the workflow, toolchain, protocol layer and team process. |
| **Creative pipeline depth** | I understand the real friction between artists, TDs, engineers, producers and production data. |
| **Rust + Python execution** | I use Rust for reliability and performance, and Python for AI tooling, pipeline automation and DCC integrations. |
| **MCP and agent tooling** | I build bridges that let AI assistants work with real tools, not just text. |
