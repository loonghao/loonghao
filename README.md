## DCC-MCP ecosystem

> **I am the author of [DCC-MCP](https://github.com/dcc-mcp)**, an open source ecosystem for connecting
> creative applications to structured AI and automation workflows. The ecosystem spans Maya, Houdini,
> 3ds Max, Nuke, Photoshop, and Unreal, with a shared protocol and application-specific adapters.

[Core](https://github.com/dcc-mcp/dcc-mcp-core) · [Maya](https://github.com/dcc-mcp/dcc-mcp-maya) · [Houdini](https://github.com/dcc-mcp/dcc-mcp-houdini) · [Photoshop](https://github.com/dcc-mcp/dcc-mcp-photoshop)
